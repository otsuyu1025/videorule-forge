# VideoRule Forge 使い方ガイド

## このツールでできること

動画を自動でチェックするためのプラットフォームです。

1. **ルールを登録する** — 「テロップは3秒以上表示する」「画面に連絡先（URL・電話番号）を表示する」など、動画制作のルールを蓄積します
2. **動画を検品する** — 登録したルールをもとに、AIが動画を自動でチェックします
3. **結果を確認・修正する** — OK / NG / 要確認 の判定を見て、必要に応じて手動で修正します

---

## ステップ1：ルールを揃える

メニューの「動画制作ルール」から入ります。

### ① 知識ソースを登録する（任意）

ルールの元となる素材を登録できます。登録しなくても手動でルールを追加できますが、登録することでAIがルール案を自動提案します。

- **ガイドラインを登録する**：「新しいソースを追加」→「ガイドライン」を選択。
  社内の制作ルール文書、クライアントからの指示書、ブランドガイドラインなど、テキストや文章で書かれたルールをそのまま貼り付けてください。AIが内容を読み取り、チェック可能なルール案として整理します。

- **お手本動画を登録する**：「新しいソースを追加」→「お手本動画」を選択。URLまたはファイルをアップロードしてください。
  「この動画のような仕上がりにしてほしい」という基準となる動画を登録します。AIが動画を解析し、そこから読み取れるルール案（構成・テキスト表示・尺など）を提案します。

- **薬機法を登録する**：「新しいソースを追加」→「薬機法をアップロード」を選択。
  薬機法の広告規制条文（**第十章 医薬品等の広告**）を登録することで、検品時に薬機法の観点でのチェックが追加されます。詳細は後述の「薬機法チェック」を参照してください。

### ② ルール候補を確認して承認する

「ルール候補」タブで、AIが提案したルールの一覧を確認します。

- **承認**：そのままルールとして採用します
- **却下**：不要なものは削除します
- 内容が惜しい場合は**編集してから承認**することもできます

### ③ ルール管理を確認する

「ルール管理」タブに、承認されたルールが一覧表示されます。ここにあるルールが動画検品で使われます。

> **ルールがないと検品ができません。** 最初に必ずルールを1件以上登録してください。

## 薬機法チェック

薬機法（医薬品医療機器等法）の広告規制に基づいたチェックを、通常の制作ルール検品と並行して実行できます。

### 薬機法ルールの登録

「動画制作ルール」→「知識ソース」→「薬機法」→「薬機法ページで編集」から登録します。

**入力方法は3種類あります：**

| 方法 | 操作 | AI使用 |
|------|------|--------|
| テキスト入力 | 条文テキストを直接貼り付け → 「AIでルールを抽出」 | あり |
| テキストファイル | .txtファイルを読み込み → 内容を確認・編集 → 「AIでルールを抽出」 | あり |
| JSONファイル | 過去にエクスポートしたJSONを読み込み → そのまま保存 | **なし** |

> **コスト節約のヒント**：登録するのは条文全文ではなく **第十章（第六十六条〜第六十八条）のみ** を推奨します。それ以外の章（許可・製造・薬局管理等）は広告審査に不要なため、AIに送るテキストを絞ることで処理コストを抑えられます。

### 判定ルールの管理

「薬機法」ページ上部の「判定ルール」セクションで、AIが抽出したルールを確認・編集できます。

- **編集**：カテゴリ名・説明・引用元（例: 第十章第六十六条）・NG例・OK例を変更
- **削除**：不要なルールを削除
- **ON/OFF**：業界・用途に応じて特定のカテゴリをオフにすると、そのカテゴリはClaudeに送信されず費用を節約できます
- **JSONエクスポート**：現在のルール一覧をJSONファイルとしてダウンロードします。次回の改正時にJSONで再インポートすれば、AI抽出をスキップできます

### 薬機法チェックのON/OFF

「設定」→「薬機法チェック」のトグルで有効・無効を切り替えられます。ルールを登録していても、ここをオフにすると検品時にスキップされます。

### 検品結果での見え方

薬機法チェックが有効な場合、検品結果に薬機法専用のセクションが追加されます。通常の制作ルールと同様に、OK / NG / 要確認 で判定されます。

## ステップ2：動画を検品する

メニューの「動画検品」から入ります。

1. 動画タイトルを入力します（省略可）
2. URLかファイルをアップロードします
3. 「検品する」を押します

AIが自動でチェックを進めます。動画の長さにより **1〜3分程度** かかります。

### 結果の見方

| 判定 | 意味 |
|------|------|
| **OK** | ルールを満たしていると判断された |
| **NG** | ルール違反が確認された |
| **要確認** | AIでは判断できなかった（目視確認が必要） |

各項目の下に「AIの判断根拠」が表示されます。

### 判定を手動で修正する

AIの判定が間違っていると思ったら、各項目の右側にある **OK / NG / 要確認** ボタンを押して上書きできます。

---

## ステップ3：検品履歴を確認する

過去の検品結果は「検品する」ボタンの下に一覧で残ります。

- クリックで展開すると、詳細な判定結果を見られます
- 「OCR解析詳細」を開くと、AIが動画から読み取ったテキストとその表示タイムラインが確認できます
- 検証が完了していないものは「**検証中...**」と表示されます（数分待つと自動で更新されます）
- 不要な履歴は右端のゴミ箱ボタンで削除できます

## よくある質問

**Q. 「要確認」が多くなるのはなぜですか？**

映像だけでは判断が難しいルールは「要確認」になります。たとえば：
- フォント名の特定（ゴシック体か明朝体かは画像から推定できますが、フォント名まで断定するのは困難です）
- 特定のロゴが表示されているかどうか（AIは画面内のロゴらしい要素は認識できますが、それが「自社の正しいロゴ」かどうかは参照画像なしには照合できません）
- ナレーション・BGMの内容（現在、音声文字起こしは無効のため）

これらのルールは目視での確認をお願いします。

**Q. ロゴの判定精度を上げることはできますか？**

現時点では、基準となるロゴ画像を登録する機能はありません。ロゴに関するルールは「要確認」になるケースが多いため、目視確認を前提としてご利用ください。

**Q. 検品が途中で止まったようです**

「検証中...」が長時間続く場合は、ページを再読み込みしてください。エラーと表示された場合は、もう一度最初から検品してください。止まったままの履歴はゴミ箱ボタンで削除できます。

**Q. ルールを後から変更できますか？**

「ルール管理」から内容の編集・削除ができます。変更は次の検品から反映されます（過去の検品結果には影響しません）。

**Q. テロップが短時間しか表示されない場合、正しく検出されますか？**

AI によるテキスト読み取り（Vision OCR）は、デフォルトで **3秒ごとに1枚** のフレームを解析します。そのため、3秒未満しか表示されないテロップは検出されない場合があります。

検出精度を上げたい場合は、設定画面の「Vision OCR のフレーム間隔」を短くしてください（例: 1秒ごと）。ただし間隔を短くすると処理時間が長くなります。

**Q. 動画ファイルの制限はありますか？**

200MB までの MP4・MOV・AVI・WebM に対応しています。

目安として **5分以内・50MB 以下** の動画で安定動作を確認しています。大きいファイルほどサーバーのメモリを多く消費するため、長尺・高ビットレートの動画はエラーになる場合があります。

**Q. 音声（ナレーション・BGM）の内容はチェックできますか？**

「設定」→「音声文字起こし」のトグルで有効・無効を切り替えられます。

有効にすると Whisper（音声認識モデル）がナレーションを文字起こしし、「〇〇と言っているか」「特定のフレーズを読み上げているか」といった音声に関するルールもチェック対象になります。

ただし Whisper モデル（約244MB）の分だけメモリを消費するため、Railway Hobby プラン（512MB）では他の処理と競合する可能性があります。動作が不安定な場合はオフに戻してください。

**Q. 薬機法ルールはどこで登録しますか？**

「動画制作ルール」→「知識ソース」→「薬機法」→「薬機法ページで編集」から登録できます。または「動画制作ルール」→「ルール管理」の最上部にある「薬機法」セクションのリンクからもアクセスできます。

**Q. 薬機法の条文全文をそのまま貼り付けてもいいですか？**

可能ですが、コスト面から非推奨です。薬機法の全文は約20万字あり、AI処理コストが高くなります。広告審査に必要なのは **第十章（第六十六条〜第六十八条）のみ** のため、その部分だけ抜き出して貼り付けることを推奨します。

**Q. 薬機法が改正されたらどうすればいいですか？**

「薬機法」ページの「ルールを更新する」セクションから、最新の条文を再登録してください。既存のルールは完全に上書きされます。JSONエクスポートを使って現在のルールをバックアップしてから更新することを推奨します。

**Q. 薬機法チェックと通常のルールチェックは同時に実行されますか？**

はい。薬機法チェックが有効な場合、通常の制作ルールと薬機法ルールが両方チェックされ、検品結果にそれぞれの判定が表示されます。
