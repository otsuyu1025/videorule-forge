# VideoRule Forge 使い方ガイド

## このツールでできること

動画を自動でチェックするためのプラットフォームです。

1. **ルールを登録する** — 「ロゴは冒頭3秒以内に表示する」「フォントはゴシック体のみ」など、動画制作のルールを蓄積します
2. **動画を検品する** — 登録したルールをもとに、AIが動画を自動でチェックします
3. **結果を確認・修正する** — OK / NG / 要確認 の判定を見て、必要に応じて手動で修正します

---

## ステップ1：ルールを揃える

メニューの「動画制作ルール」から入ります。

### ① 知識ソースを登録する（任意）

ルールの元となる素材を登録できます。

- **お手本動画を登録する**：「新しいソースを追加」→「お手本動画」を選択。URLまたはファイルをアップロードしてください。AIが動画を解析し、ルール案を提案します。
- **ガイドラインを登録する**：「新しいソースを追加」→「ガイドライン」を選択。PDFやテキストで渡している制作ルール文書をそのまま貼り付けてください。AIがルール案を抽出します。

### ② ルール候補を確認して承認する

「ルール候補」タブで、AIが提案したルールの一覧を確認します。

- **承認**：そのままルールとして採用します
- **却下**：不要なものは削除します
- 内容が惜しい場合は**編集してから承認**することもできます

### ③ ルール管理を確認する

「ルール管理」タブに、承認されたルールが一覧表示されます。ここにあるルールが動画検品で使われます。

> **ルールがないと検品ができません。** 最初に必ずルールを1件以上登録してください。

---

## ステップ2：動画を検品する

メニューの「動画検品」から入ります。

1. 動画タイトルを入力します（省略可）
2. URLかファイルをアップロードします
3. 「検品する」を押します

AIが自動でチェックを進めます。動画の長さにより **1〜3分程度** かかります。

### 結果の見方

| 判定 | 意味 |
|------|------|
| **OK** | ルールを満たしていると判断された |
| **NG** | ルール違反が確認された |
| **要確認** | AIでは判断できなかった（目視確認が必要） |

各項目の下に「AIの判断根拠」が表示されます。

### 判定を手動で修正する

AIの判定が間違っていると思ったら、各項目の右側にある **OK / NG / 要確認** ボタンを押して上書きできます。

---

## ステップ3：検品履歴を確認する

過去の検品結果は「検品する」ボタンの下に一覧で残ります。

- クリックで展開すると、詳細な判定結果を見られます
- 「OCR解析詳細」を開くと、AIが動画から読み取ったテキストとその表示タイムラインが確認できます
- 検証が完了していないものは「**検証中...**」と表示されます（数分待つと自動で更新されます）

---

## よくある質問

**Q. 「要確認」が多くなるのはなぜですか？**

音声文字起こしが無効の場合や、映像だけでは判断が難しいルール（フォント名、細かい色の確認など）は「要確認」になります。その場合は実際の動画を目視で確認してください。

**Q. 検品が途中で止まったようです**

「検証中...」が長時間続く場合は、ページを再読み込みしてください。エラーと表示された場合は、もう一度最初から検品してください。

**Q. ルールを後から変更できますか？**

「ルール管理」から内容の編集・削除ができます。変更は次の検品から反映されます（過去の検品結果には影響しません）。

**Q. 動画ファイルの制限はありますか？**

200MBまでのMP4・MOV・AVI・WebMに対応しています。
